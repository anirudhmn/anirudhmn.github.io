# Anirudh Natarajan

A minimal personal website with a dedicated games section and support and privacy pages.

- `index.html`: personal landing page
- `games.html`: game listing, including Pixel Cricket
- `support.html`: general support and links to game support
- `privacy.html`: website privacy and links to game policies
- `pixel-cricket-support.html`: Pixel Cricket support
- `pixel-cricket-privacy.html`: Pixel Cricket privacy policy

Static HTML and CSS, hosted on GitHub Pages.
